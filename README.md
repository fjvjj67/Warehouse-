# خريطة المخزن 3D

ملف واحد (`index.html`) يعرض مخزن AZAWI بشكل ثلاثي الأبعاد: 17 غرفة + 3 ممرات، بحث بالاسم أو SKU أو الباركود، وتحديد الرف والمستوى على الخريطة.

## التشغيل
افتح `index.html` بالمتصفح (يحتاج إنترنت لتحميل three.js). للنشر: GitHub Pages من الفرع الرئيسي.

## المزايا
- بحث ذكي (يتجاهل التشكيل والهمزات) + مسح باركود
- تعديل موقع المنتج **وكميته**، ويُحفظ على الجهاز (localStorage) أو على السيرفر المشترك إن توفر
- حالة المخزون: متوفر / منخفض (≤10) / نافد، وملخص بالأسفل
- عرض بقية المنتجات الموجودة على نفس الرف
- تصدير CSV لكل المنتجات

## خطوات التطوير المقترحة
1. نقل `PRODUCTS` إلى ملف `products.json` أو قاعدة بيانات (Supabase) وربطه بنظام الجرد/POS.
2. استيراد المنتجات من Excel/CSV بدل كتابتها بالكود.
3. حد أدنى مستقل لكل منتج بدل الرقم الثابت 10.
4. سجل حركة (من نقل المنتج ومتى) وتصنيف ABC لتقريب الأسرع مبيعاً من الباب.
